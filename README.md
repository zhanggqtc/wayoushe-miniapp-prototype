这是无畏契约高校运营方向的小程序交互原型，用于对外展示和设计团队后续深化。

## 在线预览

## 文件说明

- `index.html`：可点击 H5 交互原型。
- `interaction-spec.md`：交互说明书，包含信息架构、核心模块、状态规则和设计团队关注点。

## 当前产品范围

- 玩家登录后的游戏账号添加页。
- 未完成高校认证时的隐藏信息默认页。
- 高校认证三步流程：信息输入、信息校验、确认提交和成功加群引导。
- 高校瓦友社首页。
- 本校 QQ/微信群聊入口。
- 本校成员弹窗：认证顺序和段位分布。
- 本校先锋成就记录弹窗。
- 高校特权皮肤随机与下月自选槽。
- 活动与比赛中心。
- 高校先锋活动组织链路。
- 活动积分与小程序内积分商城入口。
- 首页掌瓦图文瀑布流。
- 我的页先锋身份识别与多级管理工具子页。

## 设计重点

1. 首页要突出高校归属感、皮肤权益、活动雷达和掌瓦图文内容。
2. 皮肤自选必须区分“已占位”“待锁定”“已锁定”“默认补位”。
3. 活动 Tab 顶部固定展示已报名且进行中的活动，活动详情卡需要提供报名、地点、人数、积分、状态和参与按钮。
4. 积分商城在小程序内完成商品浏览、详情查看和兑换确认，确认后跳转外部成熟周边商城承接履约。
5. 高校先锋能力不作为底部 Tab，在我的页识别身份后进入多级工具箱：一级模块、二级功能子页、独立操作模块。
